# pyfltr

多言語プロジェクトの品質チェックを一元管理し、コーディングエージェントから扱える形で提供する基盤。
Python / Rust / .NET / TypeScript・JavaScript / ドキュメントなどの
formatter・linter・testerを単一コマンドで実行する。
プロジェクト固有のカスタムチェックも統合できる。
